06 / FEATURED WORK

Case Studies

Troubleshooting

Reviving an Unbootable Laptop

Challenge
A Gateway laptop wouldn't start, and three separate faults were stacked on top of each other.
Approach
Worked through the faults one at a time. First a CMOS checksum error from a dead backup battery, where the BIOS settings had to be reset. Next, a corrupted registry hive (error 0xc00000e9). Last, a recovery USB built for UEFI that this legacy-BIOS machine couldn't boot, which was rebuilt for MBR/BIOS.
Result
The laptop boots back to Windows with the user's files intact.
Root-Cause AnalysisBIOSWindows RecoveryRufus
Security & Compliance

Audit-Ready Data Destruction

Challenge
Retired campus hard drives could still hold sensitive data, and the university needed proof that each one was destroyed.
Approach
Physically destroyed each drive's platters on a drill press and logged every device by serial number, manufacturer, capacity, interface and destruction date.
Result
An auditable record for every drive, supporting the university's data-protection compliance.
Data SanitizationAsset ManagementExcel Audit Trail
